# Blessingproject1t

A simple responsive landing page prototype inspired by Tesla's website. The project includes a hero section with navigation, model cards, and a clean footer layout.

## Features

- Responsive layout for desktop and mobile
- Hero section with custom order and existing inventory links
- Product cards for Tesla Model S, Model 3, Model X, and Model Y
- Background image hero design and centered text content
- External Google Fonts styling

## Files

- `index.html` - Main page markup
- `tesla.css` - Styling and responsive layout rules
- `Model-S.avif`, `Model-X.avif`, `Model-X-tesla.avif`, `Model-Y.avif`, `tesla-model-3.avif` - Vehicle imagery
- `Tesla background image.avif` - Page background image

## Usage

1. Open `index.html` in a browser.
2. Review the page layout and responsive behavior.
3. Update images, text, or styling as needed.

## Notes

- The page currently uses placeholder navigation links (`#`).
- The project is designed as a front-end prototype and does not include back-end functionality.
- For best results, view in a modern browser with support for AVIF images.
